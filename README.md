What is this software?
SmartBudget Manager is a simple Microsoft Excel workbook designed to help university students track their monthly income and expenses. It automatically calculates your remaining balance and gives you a visual warning if you exceed your budget.

What do I need to use it?
A computer with Microsoft Excel (2016, 2019, 2021, or Microsoft 365).

Basic computer skills (knowing how to open files, click on cells, and type).

No advanced Excel knowledge is required to use this workbook.

How do I get started? (Quick Start)
Download and open the SmartBudget_Manager.xlsx file.

Go to the Categories sheet to see your predefined budgets (Food, Transport, Rent, etc.). You can change the budget numbers here if needed.

Go to the Transactions sheet.

Start entering your data in the first empty row:

Enter the Date.

Type a Description (e.g., "Grocery shopping").

Select "Income" or "Expense" from the drop-down list.

Select a Category from the drop-down list.

Enter the amount in the Income or Expense column.

Press Enter. The Dashboard will update automatically.

Go to the Dashboard sheet to see your monthly balance and charts.

Important Rules
Do not overwrite formulas: The "Month" column in the Transactions sheet and all cells in the Dashboard sheet contain hidden formulas. Do not type over them.

Use the drop-down lists: Always use the provided drop-down lists for Type and Category so the Dashboard calculations work correctly.

One month at a time: This workbook tracks one month at a time. To start a new month, clear the transactions or save a new copy of the file.
